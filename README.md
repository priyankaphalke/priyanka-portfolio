# Priyanka Phalke — Portfolio

React + TypeScript + Vite + Tailwind + Framer Motion + Lucide.

## Edit your content
Everything lives in `src/data/portfolio.ts`: links, projects, experience, certifications.
Replace `public/resume.pdf` with your real resume. Replace `YOUR_GITHUB_URL`, `YOUR_LINKEDIN_URL`, `YOUR_EMAIL`.

## Run locally
npm install && npm run dev

## Deploy (free)
1. Create a GitHub repo, then: git init && git add . && git commit -m "Portfolio" && git branch -M main && git remote add origin <repo-url> && git push -u origin main
2. Go to vercel.com, sign in with GitHub, Add New > Project, import the repo, click Deploy.
3. Your URL appears as https://<project-name>.vercel.app
(Netlify works too: app.netlify.com > Add new site > Import from Git. Settings are in netlify.toml.)
